# ATM Simulator

A simple ATM Simulator developed using Python.

## Features

- Check account balance
- Deposit money
- Withdraw money
- Validate withdrawal amount
- Exit the ATM safely

##  Technologies Used

- Python

##  How to Run

1. Download or clone this repository.
2. Open `atm_simulator.py`.
3. Run the Python program.
4. Select an option from the ATM menu.

## Python Concepts Used

- Variables
- User input
- if-elif-else
- while loop
- Functions and basic logic
- Arithmetic operators
- break statement
